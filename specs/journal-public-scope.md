# 公開展示範圍：僅意識潮

更新：2026-10-18，依作者要求暫停公開個人首頁與 dev notes，聚焦「內容決定閱讀體驗」的意識潮實驗。

- 根網址 `/dev-notes/` 導向 `/dev-notes/my-tide`，不渲染個人作品集。
- Docusaurus docs plugin 停用，不產出 `/dev-notes/docs/...` 路由或筆記內容。舊筆記網址在新版本回傳找不到頁面。
- pages plugin 僅保留根網址導向頁，Markdown 範例頁不公開。
- 導覽列僅保留意識潮，站名與副標改為意識潮及「內容決定閱讀體驗」。
- 移除時間軸左上角回個人首頁的「折返」。作品內的返回意識潮與訊號光年的折返仍保留。
- `docs/` 與 `src/components/PortfolioHome/` 原始內容保留，方便日後另行恢復或拆站。

這是公開網站的路由與建置範圍調整，不新增登入或權限系統。GitHub Pages 需部署新建置後，正式站才會套用本次範圍。
