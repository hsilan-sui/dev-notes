# 訊號光年

2026-10-18，依 `design/component.pen` v7（原名「訊號摺子」）實作。Pencil 設計稿的功能名稱也已同步更新為「訊號光年」。摺紙仍是展開與收合的視覺意象。

## 已實作

- BB Call 旁的入口顯示「訊號光年 · 數量」，未看過的新抵達以紅點提示。數量包括原訊號與回應。
- 寬螢幕入口在 Banner 左下；1180px 以下位於兩台 BB Call 下方獨立一列，點擊區至少 44px。
- 桌面由左向右攤開橫向時間線，可用捲軸、觸控板、鍵盤或拖曳空白處左右閱讀；過去在左，現在在右。
- 596px 以下為底部展開的直式抽屜，舊訊號在上、新訊號在下，開啟時捲到最新，回應串在原處展開。
- 訊號只顯示文字、MT01／MT02 與時間。沒有名字、頭像、篩選或傳送狀態標籤。
- 點訊號展開原文、文章來源、回應及「回一句」。沒有回應時顯示「還沒有人回」。
- 回一句沿用現有 BB Call 編輯器：收到訊號的那台回覆；對話接續時由最新一句的對岸回。手機在使用者點擊當下開啟輸入欄，保留系統鍵盤的啟動時機。
- 訊號內容於抵達後才進入時間線；路途仍由河上的紅點表現。重複抵達不重複建立訊號或回應。
- 「折返」、Escape、點背景可收起；手機也能下拉頂部把手。頁面逐頁收回，焦點返回入口。回覆或文章來源動作則接續到目的位置。
- 支援 reduced motion：不做摺紙，僅淡入淡出。展開時鎖定背景捲動並限制 Tab 焦點，收起後解除。

## 資料範圍

目前沒有 API 或資料庫；訊號只記錄這次造訪，重新整理後清空。不聲稱是跨訪客公開留言。首則示範訊號來自〈大爆炸〉，保留來源連結；其餘內容來自讀者在本次造訪中實際送出的句子。不預填虛構訪客或回應。

## 實作位置

- `SignalRiver.jsx`：兩台 BB Call、傳送、抵達、對話記錄與回覆對岸。
- `SignalLightYears.jsx` / `.module.css`：入口、時間線、回應串、折返與手機抽屜。
- `SignalPager.jsx`：既有輸入介面，區分新訊號與回一句，傳送中防止重複送出。
- `signalRiver.js`：首則示範與不改寫原資料的訊號歸串函式。
- `tokens.css`：紙色、摺痕、邊框、陰影與動畫時間。

## 手機輸入與排列

- 手機寬度（596px 以下）或觸控裝置自動使用底部編輯區，不顯示桌面模擬鍵盤。
- 點「寫訊號」或「回一句」時，先同步切成可編輯輸入欄，再於同一次點擊聚焦，讓手機系統鍵盤可立即開啟。
- 編輯區配合 visualViewport 避讓鍵盤及底部安全區；背景遮罩攔截點擊，並鎖定文章捲動。
- 手機版順序：標誌／日期 → BB Call 與訊號光年 → 波浪時間軸 → 文章卡；桌面順序維持原設計。
