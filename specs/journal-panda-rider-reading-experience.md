# 接單出發：閱讀體驗

## 敘事意圖

沿用原稿的 21 段文字與像素場景。讓讀者經過外送員的不安、等待與相遇，最後回頭看自己對這棟大樓的投射。保留「你覺得呢？」的停頓，不加選項、分數或答題。

## 閱讀路徑

1. 意識潮的文章卡片顯示標題與短引，按「接單出發」直接進入作品的出發畫面，略過一般文章展開層。
2. 全螢幕中按「接下這一單」才推進故事。低解析度 Canvas 街景、像素人物、方角對話框構成同一個閱讀空間。
3. 街上 → 通廊 → 一樓 → 電梯 → 六樓。每次推進只走一段，字逐步出現；可直接顯示完整文字。
4. 女孩出現時暖光從門口透出，風聲退去；沒有額外提示解釋情感轉折。
5. 回到夜街，在「你覺得呢？」停住。可重新出發或折返文章。

## 操作與退路

- 明確按鈕推進；左右方向鍵切換段落。打字中按繼續先顯示完整文字。
- 上一段始終可用（第一段除外）。沒有自動翻頁或強制等待。
- 聲音預設關閉，讀者主動開啟後才建立 Web Audio；離開時停止並釋放。
- 「返回意識潮」及 Escape 進入宇宙結尾：先退入深空、唯一的一顆星先微微閃動，「你我都來自星塵」從透明浮現並停留，最後從原卡片的位置擴張揭回時間軸。動畫完成後還原焦點與捲動；再次按 Escape 可略過。減少動態偏好保留單顆靜態亮星、結尾文字與淡出。
- 減少動態偏好下直接顯示全文、停止場景及人物動畫。輔助科技每段讀取一次完整文字。
- 窄螢幕狀態列換行，長文字允許捲動，不裁切操作按鈕。

## 實作邊界

作品位於 `src/components/MyTide/PandaRider/`，由意識潮文章內容（blog 的 MDX）引用；只在文章資料補上 readingExperience，並在 StoryCard 為這件作品接上獨立閱讀元件；不修改首頁版面；共用沉浸閱讀器的奇點返回也沿用 CosmicReturn。不加新依賴；原檔的 Three.js import 未被使用，已移除。視覺 token 放在 `.journal-scope` 下的 `tokens.css`，版型使用 CSS Module。

替換意識潮時間軸原先顯示在〈大爆炸〉左側的 Journal Density QA Fixture 01 範例（Welcome 保留）；`2026-10-01` 是為排在〈大爆炸〉前而暫定的編排日期，並非確認過的創作日期。原 JSX 已從 `ai_workspace/panda-rider-v2.jsx` 移至作品元件。

## 已確定的宇宙收尾

這是〈大爆炸〉與〈接單出發〉固定使用的返回效果，由 `CosmicReturn` 共用，後續修改保留此節奏，不必重新設計。無垠的黑暗中只保留一顆星，先輕微明暗閃動，再讓「你我都來自星塵」在螢幕正中央從透明變清楚（位置不跟隨卡片或星星）；最後由同一顆星的位置擴張揭回卡片。背景不鋪滿星星。減少動態模式保留單顆靜態星與結尾文字，停止閃爍。
