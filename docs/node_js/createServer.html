【API_ kata_01】透過 createServer 開啟伺服器

🟧 開場白​

//>>> 實作：透過 createServer 開啟伺服器 

// 載入 http 模組
const http = require("http");

// 請求 與 回覆
const requestListener = (req, res) => {
  res.writeHead(200, { "Content-Type": "text/plain" }); // 回應 header
  res.write("hello"); // 回應內容
  res.end(); // 結束並送出回應
};

// 建立 server
const server = http.createServer(requestListener);
server.listen(3005);

🟢 DO​

👉 建立一個最基本的 HTTP Server，監聽 3005 port，並在每次收到請求時回傳一段純文字 hello。

  • 只要瀏覽器或工具（例如 curl、Postman）打：
http://localhost:3005
  • 就會看到：
hello

🟡 WHAT​

1️⃣ const http = require("http");​

  • 載入 Node.js 內建的 http 模組
  • 不需要安裝 npm 套件
  • 提供：
    • 建立 HTTP Server
    • 處理 request 與 response

2️⃣ const requestListener = (req, res) => { ... }​

這是一個 請求處理函式（callback function）

Node.js 在每次收到 HTTP 請求時，會幫你呼叫它，並傳入：

  • req：Request 物件 👉 包含 method、url、headers 等請求資訊
  • res：Response 物件 👉 用來回傳資料給 client

3️⃣ res.writeHead(200, { "Content-Type": "text/plain" });​

👉 設定 HTTP 回應的 header

  • 200：HTTP 狀態碼，代表請求成功

  • Content-Type: text/plain：

    • 告訴瀏覽器：這是純文字
    • 不會當 HTML 解析

4️⃣ res.write("hello");​

👉 寫入 回應內容（body）

  • 可以呼叫多次
  • 資料會先暫存在 response buffer

5️⃣ res.end();​

👉 結束 response，並真正送出資料

⚠️ 如果沒有呼叫 res.end()：

  • 連線會一直卡住
  • 瀏覽器會顯示 loading

6️⃣ http.createServer(requestListener);​

提示

👉 建立一個 HTTP Server

  • 傳入的 requestListener：

    • 就是「每一個請求要怎麼處理」

  • Node.js 內部會在有請求時：

    • 自動呼叫這個 function

7️⃣ server.listen(3005);​

👉 讓 Server 開始監聽 3005 port

  • OS 會把送到這個 port 的請求
  • 轉交給這個 Node.js process

🔵 HOW（整個流程怎麼跑）​

請求進來時的實際流程​

Client（瀏覽器 / curl）
        ↓
http://localhost:3005
        ↓
Node.js HTTP Server
        ↓
requestListener(req, res)
        ↓
res.writeHead()
res.write()
res.end()
        ↓
Client 收到回應

🔴 WHY（為什麼要這樣設計）​

為什麼要用 http.createServer？​

  • Node.js 是 事件驅動

  • Server 本質上就是：

    • 等待事件（request）
    • 發生時呼叫 callback

這個設計讓 Node.js 非常適合：

  • 高併發
  • I/O 密集型應用

為什麼要 res.end()？​

👉 HTTP 是「一來一回」的協定

  • Client 需要知道：

    • 回應什麼時候結束

  • res.end() 就是明確告訴 Node：

    • 「資料送完了，可以關這次請求了」

為什麼實務上很少直接用 http？​

因為：

  • 要自己處理：

    • routing
    • header
    • error
    • JSON parse

  • 所以才會有：

    • Express
    • Fastify
    • NestJS

👉 重要

  • 所有 Node.js Web Framework 的「最底層基礎」
提示

這段程式使用 Node.js 內建的 http 模組建立一個 HTTP Server，透過 createServer 註冊請求處理函式，在每次收到請求時設定回應 header、寫入內容並結束回應，最後監聽指定的 port 提供服務。
