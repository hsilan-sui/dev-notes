【JS觀念筆記_Loop】使用 For Loop 遍歷 Array

預估閱讀時間：約 3 分鐘

本篇觀念要點​

Array 負責存放多筆資料，Loop 負責把 Array 裡的資料一筆一筆取出並處理。
  1. 為什麼需要遍歷 Array
  2. 遍歷 Array 的基本結構
  3. Counter、Index 與目前元素
  4. 根據原 Array 建立新 Array
  5. 常見錯誤
這堂課的主線

原始 Array → 從 Index 0 開始 → 取得目前元素 → 處理元素 → 將結果保存到新 Array

為什麼需要遍歷 Array​

遍歷 Array，就是：

從第一個元素開始，一筆一筆處理到最後一個元素。

原始 Array
const jonas = [
  "Jonas",
  "Schmedtmann",
  46,
  "teacher",
  ["Michael", "Peter", "Steven"],
  true,
];

如果不用 Loop：

重複取得每個元素
console.log(jonas[0]);
console.log(jonas[1]);
console.log(jonas[2]);
console.log(jonas[3]);
console.log(jonas[4]);
console.log(jonas[5]);

資料一多，就會出現大量重複程式碼。

改用 Loop：

使用 Loop 遍歷 Array
for (let i = 0; i < jonas.length; i++) {
  console.log(jonas[i]);
}

不論 Array 有 6 筆、100 筆，或是 API 回傳不固定數量的資料，都可以使用同一個結構。

看到「每一筆、全部資料、逐筆處理」，可以先想到 Loop 加 Array。

遍歷 Array 的基本結構​

for (let i = 0; i < array.length; i++) {
  console.log(array[i]);
}
程式碼意思
let i = 0從第一個 Index 開始
i < array.length還有有效元素時繼續
i++前往下一個 Index
array[i]取得目前元素

為什麼從 0 開始？​

因為 Array 使用 Zero-based Index：

第一個元素 → Index 0
第二個元素 → Index 1
第三個元素 → Index 2

所以 Counter 必須從：

let i = 0;

開始。

為什麼是小於 length？​

假設 Array 有 3 個元素：

const friends = [
  "Michael",
  "Steven",
  "Peter"
];

它的長度與 Index 是：

length 是 3

有效 Index：
0
1
2

最後一個有效 Index 是：

friends.length - 1;

所以條件要寫：

i < friends.length

不能寫：

i <= friends.length

否則最後會讀取：

friends[3];

結果是：

undefined
核心規則

length 是元素數量，最後一個 Index 是 length - 1。

因此遍歷 Array 時通常使用：

for (let i = 0; i < array.length; i++) {
  // 處理 array[i]
}

Counter、Index 與目前元素​

遍歷 Array 時，Counter i 同時也是目前元素的 Index。

for (let i = 0; i < jonas.length; i++) {
  console.log(jonas[i]);
}

每一輪的變化：

i 是 0 → 取得 jonas[0]
i 是 1 → 取得 jonas[1]
i 是 2 → 取得 jonas[2]

所以這堂最重要的關係是：

Counter
    ↓
目前 Index
    ↓
目前元素
在遍歷 Array 時，i 代表目前正在處理哪一個資料位置。

為了讓程式更容易閱讀，也可以先把目前元素存進變數：

for (let i = 0; i < jonas.length; i++) {
  const currentElement = jonas[i];

  console.log(currentElement);
}

同時查看值與資料型別​

for (let i = 0; i < jonas.length; i++) {
  console.log(
    jonas[i],
    typeof jonas[i]
  );
}

可能得到：

Jonas string
Schmedtmann string
46 number
teacher string
Michael Peter Steven object
true boolean
為什麼 Array 顯示 object？
typeof [];

結果是：

object

因為 Array 在 JavaScript 中屬於一種特殊的 Object。

目前先記住結果即可。

根據原 Array 建立新 Array​

除了讀取資料，也可以根據原 Array 建立新的結果 Array。

例如，將每個元素的型別保存起來：

const types = [];

for (let i = 0; i < jonas.length; i++) {
  types.push(typeof jonas[i]);
}

console.log(types);

結果：

[
  "string",
  "string",
  "number",
  "string",
  "object",
  "boolean"
]

資料處理流程：

取得目前元素
    ↓
進行轉換或計算
    ↓
把結果加入新 Array

為什麼空 Array 要放在 Loop 外？​

正確：

const result = [];

for (let i = 0; i < source.length; i++) {
  result.push(source[i]);
}

result 只建立一次，因此每一輪的結果都能累積進去。

錯誤：

for (let i = 0; i < source.length; i++) {
  const result = [];
  result.push(source[i]);
}

每一輪都會重新建立空 Array，前一次的結果無法保留。

累積結果的基本結構
const result = [];

for (let i = 0; i < source.length; i++) {
  result.push(/* 處理後的值 */);
}

結果 Array 要建立在 Loop 外面。

填入新 Array 的兩種方式​

使用相同 Index​

const types = [];

for (let i = 0; i < jonas.length; i++) {
  types[i] = typeof jonas[i];
}

代表將結果放到指定位置。

使用 push​

const types = [];

for (let i = 0; i < jonas.length; i++) {
  types.push(typeof jonas[i]);
}

代表依序將結果加入尾端。

寫法意思
result[i] = value放到指定 Index
result.push(value)加到 Array 尾端

單純依序收集資料時，push() 通常比較直覺。

先建立空 Array，再在每一輪使用 push 保存處理結果。

實際應用​

將每個數字乘以二​

const numbers = [1, 2, 3];
const doubledNumbers = [];

for (let i = 0; i < numbers.length; i++) {
  doubledNumbers.push(numbers[i] * 2);
}

console.log(doubledNumbers);
// [2, 4, 6]

取出每位使用者的名稱​

const users = [
  { name: "Sui" },
  { name: "Amy" },
  { name: "John" },
];

const names = [];

for (let i = 0; i < users.length; i++) {
  names.push(users[i].name);
}

console.log(names);
// ["Sui", "Amy", "John"]

兩個例子的共同模式：

遍歷原始 Array
    ↓
取得目前元素
    ↓
轉換或取出需要的資料
    ↓
保存到新 Array

常見錯誤​

1. Counter 從 1 開始​

for (let i = 1; i < array.length; i++) {
  console.log(array[i]);
}

這樣會漏掉 array[0]。

正確：

for (let i = 0; i < array.length; i++) {
  console.log(array[i]);
}

2. 使用小於等於 length​

i <= array.length

會多跑一次，最後取得 undefined。

正確：

i < array.length

3. 把 Array 長度寫死​

for (let i = 0; i < 5; i++) {
  console.log(array[i]);
}

Array 長度改變時，Loop 不會自動調整。

正確：

for (let i = 0; i < array.length; i++) {
  console.log(array[i]);
}

4. 把目前 Index 寫死​

for (let i = 0; i < array.length; i++) {
  console.log(array[0]);
}

這樣會一直取得第一個元素。

正確：

console.log(array[i]);

5. 在 Loop 裡建立結果 Array​

for (let i = 0; i < source.length; i++) {
  const result = [];
}

每一輪都會重新建立空 Array。

正確：

const result = [];

for (let i = 0; i < source.length; i++) {
  result.push(source[i]);
}

6. 計算了，但沒有保存結果​

const result = [];

for (let i = 0; i < source.length; i++) {
  source[i] * 2;
}

計算結果沒有被保存。

正確：

const result = [];

for (let i = 0; i < source.length; i++) {
  result.push(source[i] * 2);
}

Codewars 常見解題模式​

看到以下需求：

Return a new array
For each element
Convert every number
Double each value
Store the results

可以先想到：

function transformArray(input) {
  const result = [];

  for (let i = 0; i < input.length; i++) {
    result.push(
      /* 使用 input[i] 計算的結果 */
    );
  }

  return result;
}

Cheat Sheet​

遍歷 Array​

for (let i = 0; i < array.length; i++) {
  const currentElement = array[i];

  console.log(currentElement);
}

建立新的結果 Array​

const result = [];

for (let i = 0; i < source.length; i++) {
  result.push(
    /* 使用 source[i] 計算的結果 */
  );
}

完整範例​

const source = [
  "Jonas",
  46,
  true
];

const types = [];

for (let i = 0; i < source.length; i++) {
  const currentElement = source[i];

  types.push(typeof currentElement);
}

console.log(types);

結尾：核心觀念整理​

使用 For Loop 遍歷 Array 時：

  • Counter 從 0 開始
  • Condition 使用 i < array.length
  • 使用 array[i] 取得目前元素
  • 不要把 Array 長度或 Index 寫死
  • 結果 Array 要建立在 Loop 外
  • 使用 push() 依序保存處理結果

遍歷 Array 的核心是：從 Index 0 開始，用 array.length 控制範圍，再透過 array[i] 取得並處理每一筆資料。 :::
