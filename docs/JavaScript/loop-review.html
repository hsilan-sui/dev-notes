【JS 觀念筆記】for 迴圈與 Array 遍歷

預估閱讀時間：約 5 分鐘

本篇觀念要點​

Loop 是把重複工作交給程式執行；搭配 Array 時，可以依照資料的順序，一筆一筆讀取與處理元素。

這篇的學習主線

重複工作 → 建立 Counter → 檢查條件 → 執行程式 → 更新 Counter → 搭配 Array 逐筆處理資料​

為什麼需要 Loop​

Loop 中文稱為「迴圈」，用途是：

重複執行同一段程式。

沒有 Loop 時：

重複撰寫相同程式
console.log("Repetition 1");
console.log("Repetition 2");
console.log("Repetition 3");

使用 Loop：

使用 For Loop
for (let rep = 1; rep <= 3; rep++) {
  console.log(`Repetition ${rep}`);
}

結果：

Repetition 1
Repetition 2
Repetition 3

Loop 可以避免重複程式碼，也符合 DRY 原則：

Don't Repeat Yourself
不要重複自己
看到「重複執行、每一筆、全部資料、逐筆處理」時，可以先想到 Loop。

For Loop 基本結構​

for (let rep = 1; rep <= 3; rep++) {
  console.log(rep);
}

For Loop 包含三個部分：

let rep = 1; // Initialization
rep <= 3;    // Condition
rep++;       // Update
部分功能
Initialization決定從哪裡開始
Condition決定是否繼續執行
Update每一輪結束後如何更新

可以理解成：

從 1 開始
只要 rep 小於或等於 3
每一輪增加 1

執行順序​

初始化
  ↓
檢查條件
  ↓
執行程式
  ↓
更新 Counter
  ↓
回到條件
For Loop 的核心流程是：初始化一次，反覆判斷，條件成立就執行，執行後更新 Counter。

Counter 計數器​

Counter 是控制迴圈進度的變數。

for (let rep = 1; rep <= 3; rep++) {
  console.log(rep);
}

每一輪：

第一輪 → rep 是 1
第二輪 → rep 是 2
第三輪 → rep 是 3

Counter 不一定要叫 rep，也可以根據用途命名：

i
count
index
step
exercise

Counter 通常使用 let，因為它每一輪都會改變。

rep++;

宣告與賦值​

let rep = 1;

可以拆成：

let rep;
rep = 1;

其中：

let rep  → 宣告變數
rep = 1  → 將 1 賦值給變數

合在一起就是：

宣告一個叫做 rep 的變數，並設定初始值為 1。

使用 For Loop 遍歷 Array​

Array 是用來存放與管理多筆資料的有順序資料結構。

const friends = [
  "Michael",
  "Steven",
  "Peter"
];

Loop 可以依照 Array 的順序，一筆一筆取得資料：

for (let i = 0; i < friends.length; i++) {
  console.log(friends[i]);
}

基本結構​

for (let i = 0; i < array.length; i++) {
  const currentElement = array[i];

  console.log(currentElement);
}
程式碼意思
let i = 0從第一個 Index 開始
i < array.length還有有效元素時繼續
i++前往下一個 Index
array[i]取得目前元素

為什麼從 0 開始？​

因為 Array 使用 Zero-based Index：

第一個元素 → Index 0
第二個元素 → Index 1
第三個元素 → Index 2

所以遍歷 Array 時通常寫：

let i = 0;

為什麼使用小於 length？​

假設：

const friends = [
  "Michael",
  "Steven",
  "Peter"
];

它的：

length 是 3
有效 Index 是 0、1、2

所以條件要寫：

i < friends.length

不能寫：

i <= friends.length

否則最後會讀取：

friends[3];

結果是：

undefined
核心規則

length 是元素數量，最後一個 Index 是 length - 1。

所以遍歷 Array 時通常使用：

for (let i = 0; i < array.length; i++) {
  console.log(array[i]);
}

Counter、Index 與目前元素​

遍歷 Array 時，Counter i 同時代表目前的 Index。

for (let i = 0; i < friends.length; i++) {
  console.log(friends[i]);
}

每一輪：

i 是 0 → friends[0]
i 是 1 → friends[1]
i 是 2 → friends[2]

可以理解成：

Counter
   ↓
目前 Index
   ↓
目前元素
Array 是有順序的資料結構，Loop 透過 Index 依序取得並處理每一筆資料。

建立新的結果 Array​

Loop 不只可以讀取資料，也可以根據原始 Array 建立新的結果 Array。

例如，把每個數字乘以二：

const numbers = [1, 2, 3];
const doubledNumbers = [];

for (let i = 0; i < numbers.length; i++) {
  doubledNumbers.push(numbers[i] * 2);
}

console.log(doubledNumbers);
// [2, 4, 6]

資料處理流程：

取得目前元素
  ↓
進行轉換或計算
  ↓
保存到新的 Array

結果 Array 為什麼放在 Loop 外？​

正確：

const result = [];

for (let i = 0; i < source.length; i++) {
  result.push(source[i]);
}

result 只建立一次，每一輪都能繼續累積資料。

錯誤：

for (let i = 0; i < source.length; i++) {
  const result = [];
  result.push(source[i]);
}

這樣每一輪都會建立新的空 Array，前一輪的資料無法保留。

填入結果的兩種方式​

使用相同 Index：

result[i] = source[i] * 2;

使用 push()：

result.push(source[i] * 2);
寫法意思
result[i] = value放到指定 Index
result.push(value)加到 Array 尾端

單純依序收集結果時，push() 通常比較直覺。

倒著遍歷 Array​

正常遍歷是從第一個元素走到最後一個元素：

for (let i = 0; i < array.length; i++) {
  console.log(array[i]);
}

倒著遍歷則從最後一個元素走回第一個元素：

for (let i = array.length - 1; i >= 0; i--) {
  console.log(array[i]);
}

假設：

const letters = ["A", "B", "C", "D"];

執行順序：

Index 3 → D
Index 2 → C
Index 1 → B
Index 0 → A

三個改變​

部分正向遍歷反向遍歷
起點0array.length - 1
條件i < array.lengthi >= 0
更新i++i--

為什麼使用 length - 1？​

不要把最後一個 Index 寫死：

let i = 3;

應該根據 Array 長度自動計算：

let i = array.length - 1;

這樣 Array 的資料數量改變時，程式仍然能正確執行。

為什麼是大於等於 0？​

i >= 0

才能包含 Index 0。

如果寫：

i > 0

會漏掉第一個元素。

巢狀迴圈​

Nested Loop 是：

一個 Loop 裡面再放另一個 Loop。

for (...) {
  for (...) {
    // 執行內容
  }
}

例如有三個運動動作，每個動作做五下：

for (let exercise = 1; exercise <= 3; exercise++) {
  console.log(`Exercise ${exercise}`);

  for (let rep = 1; rep <= 5; rep++) {
    console.log(`Rep ${rep}`);
  }
}

執行順序：

Exercise 1
  Rep 1
  Rep 2
  Rep 3
  Rep 4
  Rep 5

Exercise 2
  Rep 1
  Rep 2
  Rep 3
  Rep 4
  Rep 5

外層與內層的工作​

外層 Loop → 控制第幾個 Exercise
內層 Loop → 控制目前 Exercise 的第幾個 Rep
內層 Loop 會完整執行完，才會回到外層 Loop 的下一輪。

外層變數可以在內層使用​

for (let exercise = 1; exercise <= 3; exercise++) {
  for (let rep = 1; rep <= 5; rep++) {
    console.log(exercise, rep);
  }
}

內層可以使用 exercise，因為它仍然位於外層變數的作用範圍內。

但是 rep 只能在內層使用：

console.log(rep); // ReferenceError

如果放到內層 Loop 外，就無法存取。

While Loop​

while loop 的意思是：

只要條件成立，就持續執行程式。

基本語法：

while (condition) {
  // 條件成立時持續執行
}

例如：

let rep = 1;

while (rep <= 3) {
  console.log(rep);
  rep++;
}

和 For Loop 相比：

for (let rep = 1; rep <= 3; rep++) {
  console.log(rep);
}

兩者都有：

初始值
條件
更新

差別是 While Loop 的括號裡只放條件。

let rep = 1; // 初始值寫在外面

while (rep <= 3) {
  console.log(rep);
  rep++; // 更新寫在裡面
}

While 的適用情境​

While Loop 適合：

不知道會執行幾次，但知道什麼條件下應該繼續。

例如：

只要還沒有骰到 6，就繼續擲骰子。
let dice = Math.trunc(Math.random() * 6) + 1;

while (dice !== 6) {
  console.log(`You rolled a ${dice}`);

  dice = Math.trunc(Math.random() * 6) + 1;
}

這裡不知道會執行幾次：

可能一次
可能三次
也可能十次

只知道停止條件是：

骰子等於 6

While 可能一次都不執行​

While 會先檢查條件：

while (dice !== 6)

如果一開始 dice 就是 6：

6 不等於 6 → false

Loop 一次都不會執行。

For 與 While 怎麼選​

比較For LoopWhile Loop
適合情境知道執行次數不知道執行次數
Counter通常會使用不一定需要
初始值寫在 For 括號通常寫在外面
條件寫在括號寫在括號
更新寫在 For 括號寫在 Loop 內
常見用途遍歷 Array等待條件發生

知道要跑幾次​

for (let i = 0; i < array.length; i++) {
  console.log(array[i]);
}

例如：

遍歷 Array
執行十次
建立五個編號

不知道要跑幾次​

while (dice !== 6) {
  // 繼續擲骰子
}

例如：

直到骰到 6
直到輸入正確
直到佇列清空
直到某個狀態改變
知道要執行幾次，通常使用 For；不知道次數，只知道停止條件，通常使用 While。

Infinite Loop 無限迴圈​

如果 Condition 永遠不會變成 false，就會形成無限迴圈。

錯誤：

let rep = 1;

while (rep <= 3) {
  console.log(rep);
}

因為沒有更新：

rep++;

rep 永遠都是 1，條件永遠成立。

另一個錯誤：

for (let rep = 1; rep <= 10; rep--) {
  console.log(rep);
}

Condition 希望 rep 最後大於 10，但 rep-- 卻讓數字一直變小。

執行 Loop 前要確認
  • Counter 或條件資料是否會更新
  • 更新方向是否正確
  • Condition 最後是否有機會變成 false

常見錯誤​

1. 遍歷 Array 從 1 開始​

for (let i = 1; i < array.length; i++) {
  console.log(array[i]);
}

會漏掉：

array[0];

正確：

for (let i = 0; i < array.length; i++) {
  console.log(array[i]);
}

2. 使用小於等於 length​

i <= array.length

會多執行一次，最後取得：

undefined

正確：

i < array.length

3. 把 Index 寫死​

for (let i = 0; i < array.length; i++) {
  console.log(array[0]);
}

會一直取得第一個元素。

正確：

console.log(array[i]);

4. 把 Array 長度寫死​

for (let i = 0; i < 5; i++) {
  console.log(array[i]);
}

應使用：

for (let i = 0; i < array.length; i++) {
  console.log(array[i]);
}

5. 在 Loop 裡建立結果 Array​

for (let i = 0; i < source.length; i++) {
  const result = [];
}

每一輪都會重新建立 Array。

正確：

const result = [];

for (let i = 0; i < source.length; i++) {
  result.push(source[i]);
}

6. 計算結果但沒有保存​

for (let i = 0; i < source.length; i++) {
  source[i] * 2;
}

正確：

const result = [];

for (let i = 0; i < source.length; i++) {
  result.push(source[i] * 2);
}

7. 忘記更新 While 條件​

let i = 1;

while (i <= 5) {
  console.log(i);
}

正確：

let i = 1;

while (i <= 5) {
  console.log(i);
  i++;
}

Codewars 常見解題模式​

看到：

Return a new array
For each element
Transform every value
Double each number
Store the results

可以先想到：

function transformArray(input) {
  const result = [];

  for (let i = 0; i < input.length; i++) {
    result.push(
      // 使用 input[i] 計算結果
    );
  }

  return result;
}

解題流程：

建立結果 Array
  ↓
遍歷輸入 Array
  ↓
取得目前元素
  ↓
進行計算或轉換
  ↓
把結果 push 進新 Array
  ↓
回傳結果

Cheat Sheet​

基本 For Loop​

for (let count = 1; count <= 5; count++) {
  console.log(count);
}

遍歷 Array​

for (let i = 0; i < array.length; i++) {
  const currentElement = array[i];

  console.log(currentElement);
}

建立結果 Array​

const result = [];

for (let i = 0; i < source.length; i++) {
  result.push(source[i] * 2);
}

倒著遍歷​

for (let i = array.length - 1; i >= 0; i--) {
  console.log(array[i]);
}

巢狀迴圈​

for (let outer = 1; outer <= 3; outer++) {
  for (let inner = 1; inner <= 5; inner++) {
    console.log(outer, inner);
  }
}

While Loop​

let count = 1;

while (count <= 5) {
  console.log(count);
  count++;
}

結尾：核心觀念整理​

Loop 的目的，是把重複工作交給程式執行。

  • For Loop 包含 Initialization、Condition、Update
  • Counter 記錄目前執行到第幾輪
  • Condition 為 true 時繼續，為 false 時停止
  • Array 是有順序的資料結構
  • Loop 可以透過 Index 依序處理 Array 裡的資料
  • 遍歷 Array 通常從 0 開始
  • 條件通常使用 i < array.length
  • 使用 array[i] 取得目前元素
  • 結果 Array 要建立在 Loop 外
  • Reverse Loop 從 length - 1 開始並使用 i--
  • Nested Loop 會先完整跑完內層，再回到外層
  • 已知執行次數通常使用 For Loop
  • 未知次數、只知道停止條件時通常使用 While Loop
  • Condition 必須有機會變成 false，否則會形成無限迴圈
Array 負責存放有順序的多筆資料；Loop 負責依照順序，一筆一筆取得、處理與保存資料。

Loop 重複執行工作 → Counter 控制次數 → 搭配 Array 處理有順序的資料 → Reverse 倒敘陣列方向 → Nested 處理兩層結構 → While 根據條件持續執行
