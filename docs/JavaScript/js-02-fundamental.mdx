## 🟧 開場- JS引擎與內部環境

- > ![JS_Callstack](/img/j_01.png)


- <Highlight>Memory Heap ｜ 記憶體堆</Highlight>

:::tip Memory Heap ｜ 記憶體堆(記憶體分配的地方)
- 我們需要一個存放資料的地方，可以用來寫入儲存的變數或物件或資料的資訊
- 也就是 Memory Heap ｜記憶體堆 作為 類似蝦皮店 做為一個地方來儲存與撰寫資料
  - 其實程式就是讀寫操作
  - 這個蝦皮店就是可以分配記憶體，使用記憶或釋放記憶(可看gc章節)
  - 可以是任意資料，且無序排列，可以讓我們用變數指向不同的儲存區域(像小廚櫃)
:::

- <Highlight>Call Stack | 呼叫堆疊</Highlight>

:::tip Call Stack | 呼叫堆疊 引擎追蹤程式碼執行進度的地方
- 也需要一個可以即時執行並逐一追蹤程式碼執行最新狀況的地方
  - 用來追蹤我們在程式碼中的位置，讓我們能依序執行程式碼
:::


## 🟦 程式碼

```jsx title="Memory Heap"

//分配記憶體位置給num1變數該區域儲存值610
const num1 = 610;

//分配記憶體位置給str1變數，變數該區域儲存值"一些文字"
const str1 = "一些文字";

//分配記憶體給該物件(變數先指向物件在heap中的參考位置)
const human = {
  first: "sui",
  last: "hsilan"
}

```

```jsx title="Call Stack"

//分配記憶體位置給num1變數該區域儲存值610
const num1 = 610;

//分配記憶體位置給str1變數，變數該區域儲存值"一些文字"
const str1 = "一些文字";

//分配記憶體給該物件(變數先指向物件在heap中的參考位置)
const human = {
  first: "sui",
  last: "hsilan"
}


function subtractTwo(num) {
  return num - 2;

}



function calculate() {
  const sumTotal = 4 + 5;
  return subtractTwo(sumTotal);

}

//執行 ==> 就會使用Call Stack 呼叫堆疊(FILO 先進後出)
calculate();
```
