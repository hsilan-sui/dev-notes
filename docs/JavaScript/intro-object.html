【JS觀念筆記_Object】物件取值：點記法與中括號記法

本篇觀念要點​

陣列是依照索引排列的有順序資料結構；物件則是使用「屬性名稱」描述資料
  1. 陣列與物件的差別
  2. 點記法
  3. 中括號記法
  4. 中括號的動態取值
  5. 常見錯誤

陣列與物件的差別​

陣列：有順序的資料​

陣列裡的資料有固定順序，使用 索引 Index 取得元素。

const friends = ['Michael', 'Peter', 'Steven'];

friends[0]; // 'Michael'
friends[1]; // 'Peter'

可以理解成：

索引 0 → Michael
索引 1 → Peter
索引 2 → Steven

所以陣列在意的是：

這筆資料排在第幾個位置？

物件：用屬性名稱描述資料​

物件不使用索引來代表資料，而是使用 屬性名稱 Property Name。

const jonas = {
  firstName: 'Jonas',
  lastName: 'Schmedtmann',
  age: 46,
  job: 'teacher'
};

可以理解成：

firstName → Jonas
lastName  → Schmedtmann
age       → 46
job       → teacher

所以物件在意的是：

我要取得哪一個屬性？

點記法​

點記法 Dot Notation 適合：

已經知道固定的屬性名稱。

jonas.firstName;
jonas.age;
jonas.job;

例如：

jonas.firstName;

結果：

Jonas

點記法通常是最常見、也最容易閱讀的寫法。

中括號記法​

中括號記法 Bracket Notation 也可以取得物件資料：

jonas['firstName'];

結果和下面完全一樣：

jonas.firstName;

但是中括號有一個更重要的能力：

中括號裡可以放「變數」或「運算結果」，讓屬性名稱在執行時才決定。

中括號的動態取值​

1. 使用變數​

const prop = 'age';

jonas[prop];

JavaScript 會先取得：

prop
↓
'age'

所以等同於：

jonas['age'];

最後得到：

46

2. 使用字串拼接​

const key = 'Name';

jonas['first' + key];

JavaScript 會先計算：

'first' + 'Name'
↓
'firstName'

再變成：

jonas['firstName'];

最後取得：

Jonas

3. 根據使用者輸入取值​

const interestedIn = prompt(
  'Choose firstName, age, job'
);

console.log(jonas[interestedIn]);

如果使用者輸入：

job

那麼：

jonas[interestedIn];

就相當於：

jonas['job'];

最後得到：

teacher
中括號記法的核心

當屬性名稱不是寫死，而是來自：

  • 變數
  • 字串拼接
  • 使用者輸入
  • API 回傳資料
  • 動態欄位

就很常使用中括號記法。

點記法 vs 中括號記法​

寫法使用時機
jonas.firstName屬性名稱固定
jonas['firstName']使用字串指定屬性
jonas[prop]屬性名稱存在變數裡
jonas['first' + key]屬性名稱需要動態組合

常見錯誤​

假設：

const prop = 'age';

❌ 錯誤​

jonas.prop;

JavaScript 會真的去找名稱叫做：

prop

的屬性。

如果物件裡沒有這個屬性：

jonas.prop;

結果就是：

undefined;

✅ 正確​

jonas[prop];

執行流程：

prop
↓
'age'
↓
jonas['age']
↓
46

陣列 vs 物件快速比較​

資料結構取值方式核心概念
陣列array[0]使用索引
物件object.name使用固定屬性
物件object[key]使用動態屬性
陣列問的是「第幾個資料？」物件問的是「哪一個屬性？」
