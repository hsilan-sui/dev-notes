【config】git安裝與設定

以下我以Raspberry Pi OS Lite做為練習

🟧 更新套件清單（一定要做）​

  • 用ssh登入樹莓派
ssh 樹莓派username@ipaddr
  • 更新套件清單
sudo apt update
sudo apt upgrade -y
提示

確保抓到最新的套件索引

避免安裝舊版 git 或套件衝突

🟦 Git安裝 與 config設定​

0️⃣ git安裝​

sudo apt install git -y

1️⃣ 確認 Git 是否安裝成功​

git --version

# 輸出
## git version 2.47.3

2️⃣ 複習terminal指令​

  • 因為我使用Raspberry Pi OS Lite(Linux)為練習，就是只有終端機XD

  • 我在哪裡？$pwd=print working directory /home/sui-pi

sui-pi@raspberrypi:~ $ pwd

#輸出
#/home/sui-pi
  • 建立目錄夾/資料夾 $mkdir =make directory 
sui-pi@raspberrypi:~ $ mkdir hello

#建立了hello資料夾
  • 切換目錄夾 $cd =change directory 
sui-pi@raspberrypi:~ $ cd hello/

#切換到hello資料夾中

sui-pi@raspberrypi:~ $ pwd
#  /home/sui-pi/hello
  • 建立檔案file $touch
  • 列出該目錄夾中的檔案清單 $ls =list
  • 列出該目錄夾中的(詳細)檔案清單 $ls -al =list 
sui-pi@raspberrypi:~/hello $ ls

# index.html

----

sui-pi@raspberrypi:~/hello $ ls -al
# total 8
# drwxrwxr-x  2 sumi-pi sumi-pi 4096 Jan 17 16:24 .
# drwx------ 10 sumi-pi sumi-pi 4096 Jan 17 16:19 ..
# -rw-rw-r--  1 sumi-pi sumi-pi    0 Jan 17 16:24 index.html
  • 刪除檔案file $rm
  • 刪除目錄夾directory $rm -r 意思是針對目錄及底下檔案做遞歸刪除，把整個目錄跟其中的檔案都砍掉
  • 複製檔案 $cp =copy
  • 複製index.html 的檔案內容並命名檔案為 xxoo.html
sui-pi@raspberrypi:~/hello $ cp index.html xxoo.html

sui-pi@raspberrypi:~/hello $ ls -al
# total 8
# drwxrwxr-x  2 sumi-pi sumi-pi 4096 Jan 17 16:36 .
# drwx------ 10 sumi-pi sumi-pi 4096 Jan 17 16:19 ..
# -rw-rw-r--  1 sumi-pi sumi-pi    0 Jan 17 16:36 index.html
# -rw-rw-r--  1 sumi-pi sumi-pi    0 Jan 17 16:36 xxoo.html
  • 搬遷/移動檔案位置 $mv =move
  • 更改檔案名稱 $mv =move
  • 移動xxoo.html 到 images/資料夾下
sumi-pi@raspberrypi:~/hello $ mv index.html images/ #搬遷檔案 index.html 到images/目錄夾下
sumi-pi@raspberrypi:~/hello $ ls -al

#total 12
#drwxrwxr-x  3 sumi-pi sumi-pi 4096 Jan 17 16:41 .
#drwx------ 10 sumi-pi sumi-pi 4096 Jan 17 16:19 ..
#drwxrwxr-x  2 sumi-pi sumi-pi 4096 Jan 17 16:41 images
#-rw-rw-r--  1 sumi-pi sumi-pi    0 Jan 17 16:36 xxoo.html
  • 更改xxoo.html 檔名為 haha.html
sui-pi@raspberrypi:~/hello $ mv xxoo.html haha.html 

#更改xxoo.html 檔名為 haha.html

3️⃣ git config 設定姓名、Email​

  • 設定個人資訊

  • 檢視git目前設定並列出來 $ git config --list
  • 設定git(全域)username $ git config --global user.name "sui"
  • 設定git(全域)email $ git config --global user.email "test@mail"
設定git config

Git 每次的檔案版本發佈時，都會記錄該版本是哪位開發者做的

Commit: xxxx
Parents: xxx
Author: sui <test@mail> 
Date: JAN 12, 2026 at 04:03:22 AM
Labels: HEAD -> dev vercel/main
git的config檔案

其實輸入config指令時，是對.gitconfig檔案去做修正

MacOs：~/.gitconfig

  • 可以將全系統預設分支master改成main $ git config --global init.defaultBranc "main"
備註

這個 repo 的第一個分支名稱叫做 master

這是舊預設名稱

現在很多專案（GitHub / GitLab）都改用 main
