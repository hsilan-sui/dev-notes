# 求職入口

這一頁是給人資與面試官的快速導覽版本。

如果你只有 3 到 5 分鐘，我希望你先看到的不是零散筆記，而是我如何把需求拆開、把流程串起來，最後做成可被使用者實際操作的服務。

## 我目前想應徵的方向

- Backend Engineer
- Automation Engineer
- AI Application / Agent Engineer

## 我想呈現的工作方式

- 我會先把需求翻成清楚的系統邊界，再決定哪些要同步回應、哪些要非同步處理
- 我重視「能 demo」與「能維護」同時成立，不只把功能做出來，也會整理成文件與可追蹤流程
- 我習慣把 debug 過程、取捨與部署細節留下來，讓專案不只是一次性產出

## 建議閱讀順序

### 1. 代表專案

[LINE OA 互動作品集：端到端總覽](/docs/LINEOA-PORFOLIO/overview)

這個案例最能代表我目前的強項：FastAPI webhook、非同步派工、Worker、自動化流程、LINE reply / push 設計，以及面向 demo 的系統拆解。

### 2. 技術延伸

[AI 客服微服務設計](/docs/backend/ai-chat-service)

這篇可以看出我怎麼把即時通訊、上下文記憶與 AI 回應整理成一個可擴充的服務輪廓。

### 3. 技術筆記總覽

[筆記總覽](/docs/intro)

這裡保留我的學習軌跡與系統化整理方式，也能看到我如何把知識慢慢收斂成自己的理解。
