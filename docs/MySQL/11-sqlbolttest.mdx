### 提示：SQL的執行順序

```
FROM employees
↓
WHERE
先留下 years_employed >= 3 的員工
↓
GROUP BY
按照 role 分組
↓
Aggregate
計算每組有幾個人
↓
HAVING
只留下人數 >= 3 的組
↓
SELECT
顯示 role 與人數
```

### 題目 1：篩選人數較多的 Role

> 找出「員工人數至少 4 人」的 Role，並顯示該 Role 與員工人數。

HINT:按照這個順序想：

```text
FROM
↓
WHERE
↓
GROUP BY
↓
Aggregate
↓
HAVING
↓
SELECT
```

先不要寫 SQL，先想 4 個問題：

```text
1. 要用什麼欄位分組？

2. 每一組要算什麼？

3. HAVING 要篩選什麼條件？

4. SELECT最後顯示什麼？(最後每一組，我要顯示「組別名稱」＋「這組算出來的什麼結果」？)
```


> 解題：
```sql
SELECT role, AVG(years_employed) AS 員工數量
FROM employees
GROUP BY role
HAVING AVG(years_employed) >= 5;
```
